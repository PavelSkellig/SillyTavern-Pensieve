# План обновления интерфейса 1.1.0

ТЗ от 9 ноября 2026: выбор границ без открытия окна; компактные карточки; статусы по фактическому сформированному блоку; две секции памяти; фильтры архива. Существующая генерация, сохранение, скрытие и внедрение не меняются.

Выбранный подход: `src/view-state.js` — чистая проекция результата существующего `Engine.refreshMemory()` в статусы и фильтры; `src/ui.js` — выбор диапазона, карточки и секции; `style.css` — только изолированное оформление. Временные границы сохраняются отдельно как состояние интерфейса вкладки браузера, без изменения реплик или архива. При блокировке памяти движок не передаёт весь блок, поэтому интерфейс не должен изображать частичное внедрение.
