# Омут памяти: план реализации

**Цель:** самостоятельное UI-расширение SillyTavern 1.19.0 с ручными сводками и арками, постоянным архивом каждого чата и внедрением выбранной памяти.

**Архитектура:** JavaScript ES modules без обязательных зависимостей; `core.js` отвечает за записи, источники, версии, импорт и состав памяти; `engine.js` — за подтверждённые операции и журнал незавершённых действий; `host.js` — за проверенные API ST; `ui.js`, `panel.html`, `style.css` — за русскоязычный интерфейс. Отдельный Git-проект в этой папке; предыдущий Range Summary не изменяется.

Пользователь передал полное ТЗ и разрешил самостоятельную разработку и публичную публикацию. Реализационные решения принимаются без дополнительных согласований. Исходное ТЗ с личными подписями в репозиторий не включается.

## Ограничения и решения

- Только ручная генерация; два независимых пользовательских промпта, изначально пустые.
- `chatMetadata.pensieve` хранит архив. Глобальные настройки содержат только настройки и пресеты.
- Проверка записи через чтение серверного файла после штатного сохранения, включая групповые чаты.
- Журнал операции сохраняется до исключения. При сбое доступны завершение и восстановление. История никогда не удаляется.
- UUID в `message.extra.pensieve.id` и контрольная сумма содержания защищают от смены индексов; неоднозначные/изменённые источники не восстанавливаются автоматически.
- Чужое исходное Hide сохраняется. Общий флаг Hide не содержит владельца; повторное стороннее скрытие уже скрытого сообщения неразличимо средствами ST. Это ограничение явно описывается.
- Активные арки подавляют связанные сводки. Пересекающиеся активные арки блокируют генерацию до ручного исправления.
- Превышение лимита памяти блокирует обычную генерацию через штатный generate_interceptor; текст не обрезается и записи не выбираются автоматически.
- Ограничение архива: предупреждение при 5 MiB; блокировка расширяющей записи при 20 MiB с доступным экспортом. Серверный лимит ST 500 MB, но прокси и устройства могут иметь меньший предел.
- Импорт не скрывает источники; сопоставление выполняется только по существующим UUID и контрольным данным.
- Темы только внутри расширения; тёмная сине-бронзовая и отдельный светлый вариант, одна колонка на мобильном.

## Особые проверки

Ошибки сохранения без исключения; закрытие страницы между фазами; изменение/свайп/удаление исходника; ветвление чата; невалидный JSON и конфликт ID; размер памяти и лимиты; переключение чата во время генерации; ранее скрытые сообщения; замена сводки, используемой аркой.
