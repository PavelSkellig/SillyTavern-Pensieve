# Исправление строки настроек в 1.0.1

Вместо одиночной кнопки установлен самостоятельный блок стандартного компонента SillyTavern: внешний контейнер, `inline-drawer`, заголовок `inline-drawer-toggle inline-drawer-header`, штатная стрелка и `inline-drawer-content`. Контейнер — непосредственный сосед других расширений внутри `extensions_settings2`; вложения в чужие настройки нет.

Вся новая стилизация ограничена `#pensieve-settings`. Внешний блок, строка и панель используют `width: 100%`, `max-width: 100%`, `min-width: 0`, `box-sizing: border-box`. Заголовок не переносится, стрелка прижата вправо. Кнопки расположены в одной колонке `minmax(0, 1fr)` и занимают одинаковую ширину. Раскрытие и анимацией управляет сама SillyTavern; Enter и пробел также доступны.

Палитра строки: `#14243D`, кнопок: `#263F60`, бронза: `#B79C73`, текст: `#F0E8DC`. Остальные окна архива сохранены.

Проверка `tests/settings-ui.mjs` выполняется в отдельной настоящей ST 1.19.0 с Playwright и Edge. Исходная версия не прошла проверку наличия полноценной строки. Исправленная проверяется на ширинах 320, 375, 390, 430 и 1280 пикселей: полная ширина, отсутствие горизонтального переполнения, одна строка заголовка, шесть одинаковых кнопок, раскрытие/сворачивание, переходы, клавиатура и неизменность метаданных чата. Это проверка размеров экранов iPhone в браузере, а не испытание на физическом iPhone/Safari.

```sh
node tests/settings-ui.mjs /absolute/path/to/playwright/index.mjs http://127.0.0.1:18272
```

44 существующих теста и проверка синтаксиса сохранены. В интеграционном тесте изменён только селектор входа в создание сводки. Модули `src/core.js`, `src/engine.js`, `src/host.js`, загрузка и механизм внедрения памяти не менялись.
