# Менеджер воспоминаний 1.2.0

9 ноября 2026 года. Обновление существующей версии 1.1.0 по подтверждённому ТЗ. Референс [ST-ImageManager](https://github.com/Nufahi/ST-ImageManager) использован для принципов поиска, фильтров, условной панели выбора и мобильного рабочего окна. Код, оформление и хранилище изображений не переносились.

## Что изменилось

- В штатном дополнительном меню сообщения две закладки SVG: плюс и галочка. Видимый размер 18 px, кнопки 32 px на компьютере / 36 px на узком экране. Текста внутри нет; `title`, `aria-label`, `aria-pressed` и один обработчик `click` сохранены. Соседние действия ST не стилизуются.
- Выбор границ оставляет уведомление и отметки в чате, не открывает окно и не сбрасывается при закрытии. Очистка называется «Сбросить диапазон». Существующее отдельное временное состояние каждого чата сохранено.
- Поиск по названию и полному тексту работает вместе с фильтром фактической активности. Во время ввода обновляется только список результатов, поле сохраняет фокус и экранную клавиатуру.
- Панель выбора отсутствует при нуле отметок. Выбранные сводки показаны целиком, с количеством, перестановкой, возвратом к исходному порядку и снятием отметок. Поиск и фильтр сохраняют скрытый ими выбор. При участии сводок в любой существующей арке показывается предупреждение.
- Нумерованные названия не перенумеровываются. Полный текст не раскрывается в карточках автоматически. Сохранены открытие, редактирование, включение/отключение, версии, перегенерация, экспорт, удаление и восстановление исходников.
- «Сейчас используются» отображает точную последовательность фактического снимка движка, «Не используются» — остальные записи. Глобальное отключение, блокировка и предварительный текст разделены. Токеновая блокировка подписана «Не помещается в лимит».
- Настройки сгруппированы без изменения их значений и обработчиков. На узком экране основное окно полноэкранное, с безопасными отступами, отдельной прокруткой содержимого и доступной X.
- Текущая вкладка выделена цветом: устранён конфликт прежнего прозрачного фона навигации, проверка сначала воспроизвела его в браузере.

## Порядок и сохранность

`src/order.js` — чистая функция: находит текущие позиции исходных UUID, для арок раскрывает связи с исходными сводками. Не анализирует даты внутри текста и не записывает метаданные. При недоступных/неоднозначных источниках или пересечении диапазонов возвращает входной порядок и предупреждение.

Архив сортируется отдельно по категориям. По умолчанию выбранные сводки также сортируются по источникам; после ручной перестановки порядок сохраняется, в том числе при добавлении следующей сводки. `generateArc()` получает копию именно показанного списка. Промпт и текст входа собираются существующим кодом; скрытых новых инструкций нет.

В `Engine.memory()` меняется только последовательность уже отобранных `memoryEntries()` записей. Арки чередуются с самостоятельными сводками по исходным диапазонам. Подавление связанных сводок, конфликты арок, целостная блокировка лимитом, формат текста и способ внедрения прежние. Сортировка не выбирает, какие записи отключать.

`src/host.js`, `index.js`, методы генерации/сохранения/восстановления и схема архива не изменены. Пользовательские тексты, названия, версии, связи, активность, пресеты и настройки не мигрируют и не очищаются. Доступен прежний JSON-экспорт архива и промптов. Для отката кода сохранён тег `v1.1.0`. Личные пользовательские архивы при разработке не открывались и не изменялись.

## Проверки

Отдельная ST **1.19.0**, Node.js **24.16.0**, синтетические чаты, Edge/Chromium и Windows WebKit через Playwright с параметрами iPhone 13. Ответ модели имитируется только на границе HTTP; DOM, события, токенизаторы, построитель промпта, серверное сохранение и Hide настоящие. В WebKit-фикстуре отключён встроенный TTS из-за отсутствия Web Speech в Windows-сборке; ошибки страницы не подавляются.

- `npm test`: **67/67**, включая перемещённые/удалённые/дублирующиеся источники, смешанный порядок арок и сводок, консервативный fallback, буквальный ручной порядок, неизменность данных и диапазон из 150 000 источников без переполнения стека аргументов.
- `npm run check`: **7 модулей**, согласованность версии и наличие установочных файлов.
- `manager-ui.mjs`, Chromium и WebKit: маленькие иконки, касания по SVG, отсутствие автопоказа, названия/полный текст в поиске, фокус, фильтр, скрытая при нуле панель, ручной порядок при дополнительном выборе, предупреждение о существующей арке, ровно один явный запрос с точным порядком и пользовательским промптом, смешанная память без дублей, полноэкранные размеры 320×640 / 390×420 / 430×900, X, полная неизменность JSON архива и промптов после перезагрузки.
- `ui-memory.mjs`, Chromium и WebKit: сохранение диапазона после закрытия/перезагрузки, фактические статусы, активация и деактивация сразу меняют реальную вставку, глобальное отключение, лимит и восстановление после него, отдельные секции, неизменность текстов, изолированный CSS, прокрутка и закрытие.
- `settings-interactions.mjs`, WebKit: раскрытие/сворачивание, компактная закрытая строка, сохранение состояния, 18 касаний по шести кнопкам, один переход на касание, правильная вкладка, X и возврат управления, отсутствие изменений данных и ошибок страницы.
- `settings-ui.mjs`: строка на всю ширину, одна строка названия, шесть кнопок, раскрытие/сворачивание на ширинах 320/375/390/430/1280.
- `integration.mjs`: сводка → редактирование → подтверждение → проверка сохранения → Hide; арка с сохранением исходных сводок; обычный ответ персонажа без дублей и без изменения вставок World Info/Summarize; лимит останавливает запрос; промпты и архив после перезагрузки; отдельные чаты, ветки и группа; ошибка модели; прерванное сохранение, журнал, восстановление; JSON merge без скрытия.

Проверки покрывают все 24 пункта ТЗ. Новый тест иконок сначала воспроизвёл длинные подписи и упал, затем прошёл с исправленным UI. Тесты порядка воспроизводили старую сортировку и переполнение аргументов до исправления. Независимое ревью изменений не выявило замечаний к корректности или сохранности данных. Контрольные снимки интерфейса просмотрены.

Это проверка WebKit с мобильными параметрами, а не испытание на физическом iPhone и его экранной клавиатуре. Версии/темы/сторонние расширения из личной установки пользователя недоступны; конкретная причина ранее описанного зависания той установки не установлена. В отдельной тестовой ST запуск и повторное открытие проходят без необработанных ошибок страницы.

## Повторение

Только на отдельной тестовой ST; скрипты создают синтетические персонажи и меняют тестовые настройки. Путь Playwright и URL передаются явно. Для WebKit требуется установленная сборка браузера (`PLAYWRIGHT_BROWSERS_PATH`, если она расположена нестандартно).

```sh
npm test
npm run check
node tests/manager-ui.mjs /path/to/playwright/index.mjs chromium http://127.0.0.1:18273
node tests/manager-ui.mjs /path/to/playwright/index.mjs webkit http://127.0.0.1:18273
node tests/ui-memory.mjs /path/to/playwright/index.mjs chromium http://127.0.0.1:18273
node tests/ui-memory.mjs /path/to/playwright/index.mjs webkit http://127.0.0.1:18273
node tests/settings-interactions.mjs /path/to/playwright/index.mjs webkit http://127.0.0.1:18273
node tests/settings-ui.mjs /path/to/playwright/index.mjs http://127.0.0.1:18273
node tests/integration.mjs /path/to/playwright/index.mjs http://127.0.0.1:18273
```
