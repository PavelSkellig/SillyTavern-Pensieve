# v1.9.2 · Уведомления и восстановление копий

Дополнение к v1.9.1 по «текст (19).txt». По прямому указанию пользователя ревью, автоматические проверки и браузерные тесты для этой версии не запускались. Работоспособность на устройстве этим выпуском не подтверждена.

## Уведомления

Ошибка появляется одной компактной строкой перед полем ввода, без автоматического раскрытия подробностей. Строку можно развернуть, свернуть и закрыть. Закрытие скрывает уведомление, сохраняя запись в прежнем журнале диагностики. Компактная и подробная формы взаимно исключаются.

Ошибка в генерации, сохранении или восстановлении сворачивает соответствующее окно, сохраняя его состояние. «Вернуться к операции» в подробностях уведомления или записи журнала открывает то же окно и тот же результат. Повторная ошибка начинает с компактного состояния; дублирующая большая плашка внутри основной панели не создаётся. Повторное открытие не запускает запрос к модели.

Стили ограничены элементами расширения. Уведомление находится в обычном потоке перед полем ввода, а раскрытая часть ограничена по высоте и прокручивается.

## Восстановление резервной копии

Убран безусловный запрет при наличии незавершённой операции. Перед восстановлением проверяются текущая квитанция и серверная запись:

- Подтверждённый результат завершается с прежними ID и освобождает блокировку.
- Отсутствующий результат при подтверждённом исходном состоянии сохраняется в архив без активности; его исходники возвращаются существующим механизмом. После этого продолжается выбранное восстановление копии.
- Старая завершённая операция восстановления копии сверяется с сервером и перестаёт блокировать следующий импорт.
- При неизвестном результате, изменённом чате/архиве или ещё выполняющейся нативной записи данные не перезаписываются. Доступно повторение проверки того же файла.

Режим объединения и существующее сопоставление происхождения записей сохранены: совпадающие тексты не заменяются, связи и ID не создаются заново. Замена остаётся отдельным явно подтверждаемым режимом; автоматического удаления существующих записей нет. Файл копии сохраняется в состоянии диалога при ошибке.

Перед записью проверяется серверное исходное состояние для отката. Откат не запускается поверх продолжающейся записи или новых изменений. Неподтверждённая копия сохраняет маркер незавершённого восстановления и не внедряется в память модели.

## Диагностика

В журнал добавлены выбранные технические поля: тип и ID обнаруженной операции, этап, факт проверки сервера, результат, причина остановки и безопасное действие. Обычные UUID отображаются непосредственно; нестандартные идентификаторы представлены стабильной технической ссылкой. Тексты воспоминаний и содержимое файла копии в эти поля не попадают.

Генерация воспоминаний, пользовательские промпты, Memory Echo и формат резервной копии не менялись.
