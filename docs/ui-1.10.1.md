# v1.10.1 · Визуальный эталон и последние сокращения

Обновление поверх 1.10.0 по «текст (21).txt» и двум предоставленным изображениям. Прямое указание пользователя «без review и тестов» сохраняется: ревью, автоматические проверки, браузерные и приёмочные тесты не запускались. Совпадение с макетом на устройстве и работу Safari этот выпуск не подтверждает.

## Перед установкой

В установленном расширении откройте **Настройки → Обслуживание → Экспортировать всё**, сохраните JSON, затем обновите расширение и перезагрузите SillyTavern. Это существующая полная резервная копия с архивом, связями, статистикой, промптами и настройками. Автоматического экспорта личных данных или миграции архива обновление не выполняет.

## Композиция интерфейса

- Предоставленная чаша занимает всю ширину шапки; название, подзаголовок, фактическая версия и кнопки находятся на нижней полупрозрачной подложке. Кадрирование cover сохраняет пропорции; изображение не растягивается и не используется как миниатюра.
- Пять вкладок с символами остаются в одной строке. На узком экране прокручивается только навигация; названия не разбиваются по буквам.
- Главная следует композиции эталона: заголовок и пояснение, две карточки создания, подсказка о границах в чате, состояние памяти, три карточки с реальными количествами, Memory Echo с лимитом и индикатором, переход к памяти и последние сокращения.
- Полуночный сине-бирюзовый фон, бронзовые линии, светлый текст и полупрозрачные карточки ограничены CSS-классами расширения. Светлая пользовательская тема сохранена.

## Статистика

«Последние сокращения» строятся из трёх последних записей архива по сохранённым датам статистики/обновления. Все уровни поддерживаются; демонстрационные числа макета не используются. Текущая незавершённая запись исключается; при неподтверждённой записи или восстановлении копии список ожидает подтверждения. Отдельного общего результата и суммы экономии нет.

Для растущего текста показываются «Увеличение объёма», «Рост» и положительное изменение со знаком +. Для старой или несоответствующей текущему тексту статистики — «Статистика недоступна». Метаданные 1.10.0, история, рецепты токенизации и форматы обмена не менялись. Счётчик Memory Echo использует прежний полный сформированный блок, а не сумму записей.

## Макрос и существующие функции

В режиме макроса показано предупреждение, если memory_echo не найден во включённых текстах активного Chat Completion-пресета. Проверка читает исходные поля Prompt Manager без подготовки промпта и выполнения других макросов. Динамические вставки и непроверенный режим явно обозначены; окончательное наличие определяется прежним механизмом при отправке. Найденный макрос имеет прежний приоритет над автоматической подстановкой.

Настройки организованы как «Основные настройки», «Подстановка памяти (Memory Echo)» и закрытое обслуживание. Действие восстановления исходников осталось у конкретной главы; общая кнопка восстановления всех сообщений из настроек убрана. Безопасное восстановление незавершённой операции сохранено.

Генерация, компиляция, внедрение, хранение, IDs, связи, пресеты, исходная видимость сообщений, уведомления и фоновые операции не переписывались.
