# Pensieve approved reference v1.4 implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task. Steps use checkbox syntax for tracking.

**Goal:** Apply the user-approved reference preview to the existing v1.3.0 extension and publish v1.4.0.

**Architecture:** Retain Engine, Host, core storage and memoryViewState unchanged. Extend the existing UI instance with a DOM-preserving minimized state, then restyle and compact existing views without replacing their handlers. Use the existing native dialog and extension drawer.

**Tech Stack:** Native JavaScript modules, semantic HTML, scoped CSS, Node tests, disposable SillyTavern 1.19.0 with Playwright Chromium/WebKit.

**Spec:** User-approved preview pensieve-v14-reference.html in the visualization directory; Downloads/Telegram Desktop/текст 2.txt and the supplied screenshot. User approved implementation on 9 November 2026.

## Global Constraints

- No changes to generation, storage, injection, source hiding, chronology or saved user texts.
- All five tabs share the approved blue/bronze, serif headings, compact navigation and card design.
- Minimize preserves unsaved inputs, active tab and memory; Close removes the restore entry.
- Restore is a single in-flow control above the chat composer, never a blocking overlay.
- iPhone widths and short viewports must keep controls reachable and avoid horizontal overflow.

## Review Focus

- Asynchronous close events must not erase a newly restored window state.
- Chat changes while minimized must not expose actionable records from the old chat.
- Background refresh while minimized must preserve unsaved prompt/editor text.
- Native dialog close must release the top layer and keep ST controls usable.
- Long titles, linked arcs and large token counts must fit narrow phone layouts.
