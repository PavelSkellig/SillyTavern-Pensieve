# Компактный интерфейс 1.2.1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Выполнить подтверждённое пользователем ТЗ «текст (2).txt» поверх 1.2.0 и опубликовать обновление.

**Architecture:** Перестроить только DOM главной и записей архива в `src/ui.js`, общий заголовок в `panel.html` и изолированные стили. Предпросмотр по умолчанию содержит короткие однострочные фрагменты; раскрытие лениво строит полный диапазон из уже выбранных сообщений. Версия берётся из загруженного UI-модуля, а не из отдельно обновлённого manifest.

**Tech Stack:** Существующие ES modules, semantic HTML, CSS, Node test, Playwright, отдельная ST 1.19.0.

**Spec:** Прикреплённый пользователем «текст (2).txt»: компактная главная, раскрываемый предпросмотр, строки архива, сохранность функций/данных/пояснений, видимая версия. Пользователь явно выбрал внесение и публикацию поверх 1.2.0.

## Global Constraints

- Не изменять core/engine/host/order, генерацию, промпты, формат данных или активность записей.
- Не менять стандартные стили ST и не удалять существующие пояснения и действия.
- Не ослаблять защиту повторного диапазона.
- Минимум рамок; прежняя сине-бронзовая палитра; ширины 320–430 и короткий экран.
- Ручной выбор границ не открывает окно; закрытие не сбрасывает диапазон.

## Review Focus

- Очень длинные и многострочные исходники: короткое исходное представление и доступность полного текста.
- Один источник, пустой/обратный диапазон и диапазон, уже сохранённый в нескольких сводках.
- Смена диапазона после раскрытия: старые сообщения не остаются в предпросмотре.
- Узкий экран, большие токены/названия: читаемость, внутренняя прокрутка, доступная X.
- Версия manifest обновлена, UI закеширован: отображается версия реально загруженного JS.

## Ledger

- Исходная причина по коду: `home()` всё ещё строит прежний большой контейнер и два фрагмента по 200 символов; в `panel.html` нет номера версии. Архив 1.2.0 уже имеет поиск/выбор, но использует фоновые `.pv-card` с действиями в несколько рядов.
- Ruling: полный предпросмотр содержит весь выбранный диапазон, строится только при раскрытии — пользователь может проверить все исходники; на закрытой панели нет затрат на их DOM.
- Ruling: обновление уже разрешено явно, дополнительное подтверждение публикации не требуется.
- RED→GREEN: отсутствие версии воспроизведено на 1.2.0. Для нескольких совпадений отдельно воспроизведена разрастающаяся заметка и проверено сокращение до количества при сохранении всех вариантов select.
- Проверено: 67 unit-тестов, check, компактный UI в обоих движках и с прежним шаблоном, manager/memory/settings WebKit, полный integration Chromium. Копии архивов/промптов совпадают; защищённые модули не изменены.
