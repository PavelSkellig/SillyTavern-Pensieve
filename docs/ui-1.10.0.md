# v1.10.0 · Интерфейс и индивидуальная статистика

Обновление существующего расширения по «текст (20).txt». По сохраняющемуся прямому указанию пользователя ревью, автоматические проверки и браузерные тесты не запускались. Отображение и поведение на физическом iPhone/Safari не проверялись.

## Интерфейс

- В шапке используется предоставленная пользователем иллюстрация серебряной чаши с голубым водоворотом. Оригинальный файл включён без обработки; object-fit: contain сохраняет изображение целиком. Замок и декоративный силуэт больше не создаются.
- Главная содержит «Создать часть», «Создать том», количества записей, состояние и объём Memory Echo, переход к памяти. Формы создания главы и блока последних действий на главной нет. Глава создаётся существующими тремя значками в чате: начало, конец, создание.
- Архив сохраняет поиск, фильтры, флажки, порядок выбора, редактирование, версии и восстановление исходников.
- Память показывает раскрываемую структуру «Том → Часть → Глава» с небольшими символами, активный и архивный разделы, полный предпросмотр Memory Echo и обновление. Вложенные карточки создаются при раскрытии. Повторная связь отображается ссылкой. Состав и подавление вложенных записей в сформированном блоке определяет прежний компилятор.
- Подстановка, роль, глубина, шаблон, лимит и остальные параметры находятся в настройках. Резервные копии, незавершённые операции и диагностика помещены в закрытый по умолчанию блок «Обслуживание». Открытое состояние можно сохранить при навигации текущего сеанса.
- Добавлен параметр отображения некликабельных меток сообщений. Их цепочка по-прежнему содержит только существующие главы, части и тома.

Для новой установки и отсутствующей настройки используется «Никуда — только макрос», шаблон {{memory_echo}}. Существующие выбранные режимы, шаблоны, промпты и пользовательские настройки не сбрасываются. Макрос предназначен для используемого пресета SillyTavern, а не текста ролевого чата.

## Статистика записи

При первом сохранении новой главы, части или тома фиксируются объёмы фактического исходного материала операции и готового текста, способ подсчёта и оценка по длине текста. Генерационный промпт в статистику сжатия не входит. Для части используются тексты и заголовки выбранных глав; для тома — выбранных частей. Сообщения чата повторно не добавляются.

Раскрываемая статистика показывает «До», «После», «Сэкономлено» и процент сокращения. Отрицательная экономия означает увеличение объёма. Суммарной экономии всех уровней и таблицы «Общий результат» нет.

Используется штатный серверный токенизатор выбранной модели, а при доступности — штатный удалённый токенизатор подключения. Его рецепт фиксируется для операции. Для редактирования результата используется тот же токенизатор; исходный объём сохраняется. При недоступности токенизатора применяются одинаковые приблизительные оценки источника и результата, обозначенные ≈. При поздней недоступности исходного токенизатора первоначальный подсчёт также остаётся сохранённым и видимым отдельно. Оценка по длине — один токен на четыре символа.

Подсчёты ограничены по времени; неудачный дополнительный подсчёт не запрещает сохранение воспоминания. Загрузка вкладки не токенизирует весь архив: карточки используют сохранённые значения.

Полный счётчик Memory Echo использует объём прежнего сформированного блока, включая заголовки, пометку о прошлом, разделители и форматирование. Это отдельный показатель, а не сумма статистики карточек. Показываются лимит, процент, остаток или превышение. При выключении либо блокировке указано, что сформированный блок сейчас не передаётся.

## Совместимость и данные

Статистика — необязательное поле compression в прежней записи и истории версий. Формат архива/резервной копии остаётся версии 1; обязательной миграции или пересоздания записей нет. Старые записи остаются без придуманной статистики и показывают «Нет данных». Новые значения включаются в обычные резервные копии и экспорт. При объединении отсутствующая статистика может дополняться только для совпадающего содержимого; имеющиеся значения и тексты сохраняются.

Механизмы генерации, Memory Echo, владения исключением сообщений, первоначальной видимости источников и восстановления не переписывались. Сохранены пользовательские пресеты трёх промптов.
