# Менеджер воспоминаний 1.2.0 — план

ТЗ из «Тз .txt» подтверждено пользователем: обновить поверх 1.1.0 и опубликовать в существующем репозитории. Референс ST-ImageManager используется только для принципов панели поиска/фильтров, множественного выбора и мобильного рабочего окна; его код и хранилище изображений не переносятся.

## Архитектура и границы

Сохранить ядро генерации, пользовательские промпты, хранилище и данные. Новое `src/order.js` чисто определяет порядок повествования по текущим UUID исходных сообщений; для арок раскрывает связи со сводками. При отсутствии надёжных источников или пересечении диапазонов возвращает исходный пользовательский/ранее действовавший порядок и предупреждение. В `Engine.memory()` используется этот порядок и тот же текст/набор активных записей. `memoryText` получает необязательный готовый порядок, прежний вызов совместим.

Поиск, выбранные чекбоксы и ручной порядок арки — состояние UI. Выбор по умолчанию сортируется по исходникам, стрелки меняют порядок вручную, в генерацию передаётся именно показанный список. Дополнительных запросов модели нет. Нумерация, тексты, история версий, связи, пресеты и настройки не мигрируют и не очищаются. Резервная копия кода — существующий тег v1.1.0; для архивов сохраняется штатный JSON-экспорт.
