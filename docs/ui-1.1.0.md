# Интерфейс 1.1.0

Обновление по ТЗ от 9 ноября 2026 года. Существующее расширение и все его функции сохранены.

## Реализация

- Выбор начала/конца не вызывает `open()` или `showModal()`. Сохраняются только данные выбранных границ интерфейса, выводится короткое уведомление, обновляются классы границ в чате.
- Закрытие окна не очищает диапазон. Временный выбор каждого чата сохраняется в `sessionStorage` текущей вкладки. Для идентичности используются существующий UUID, ссылка на сообщение и контрольная сумма из существующего `core.js`. Если известная ссылка удалена, она не заменяется похожим сообщением. После перезагрузки неуникальное совпадение без UUID не считается надёжным источником. Реплики и архив этим выбором не изменяются.
- Новый `view-state.js` — чистая, не сохраняемая проекция снимка `Engine.refreshMemory()`. Активность выводится из фактически допускаемого движком блока. Флаги выбора, замещение аркой и временная отметка для арки разделены.
- При отключении или блокировке ни одна запись не показывается как реально внедряемая. Лимит по прежней логике блокирует весь блок. Отдельный предварительный просмотр сохраняет доступ к выбранным текстам, не выдавая их за внедряемые.
- Архив: Сводки/Арки, фильтр Все/Активные/Неактивные, компактные карточки с основным статусом, метаданными и тремя основными действиями. Остальные действия и технические пояснения доступны в раскрывающемся меню.
- Активная память: «Сейчас в памяти модели» и «Только в архиве», фактический текст, копирование, обновление, отключение и существующий лимит токенов.
- Все CSS-селекторы ограничены собственными диалогами, блоком настроек или собственными элементами в чате. Уменьшены отступы и заголовки; все функции и пояснения сохранены.
- Обработчики регистрируются при загрузке расширения, а не при каждом открытии окна.

`src/core.js`, `src/engine.js`, `src/host.js` и `index.js` остаются идентичными предыдущей версии: генерация, хранение, исключение и внедрение не переписаны. Миграции архива или пользовательских промптов нет.

## Проверки

Новые unit-тесты проверяют фактическую активность, глобальное отключение, целостную блокировку лимитом, замещение аркой, временный выбор для арки, фильтры, номера арок и неизменность входных данных. Тесты диапазона воспроизводили ошибку подмены удалённой границы одинаковым соседом и теперь проверяют её исправление.

`tests/ui-memory.mjs` работает в отдельной ST 1.19.0 с тестовыми историями и параметрами iPhone 13. Проверяются отсутствие всплывающего окна, отметки и сохранение диапазона, карточки, фильтры, отдельные секции, немедленное обновление реальной вставки при изменении активности, отключение, лимит, отсутствие дублей арки, сохранение после перезагрузки, неизменность текстов/промптов, изоляция CSS, короткий экран и закрытие.

```sh
node tests/ui-memory.mjs /absolute/path/to/playwright/index.mjs chromium http://127.0.0.1:18273
node tests/ui-memory.mjs /absolute/path/to/playwright/index.mjs webkit http://127.0.0.1:18273
```

В WebKit-фикстуре отключён только встроенный TTS отдельной тестовой ST из-за отсутствия Web Speech API в Windows-сборке движка. Ошибки страницы не подавляются. Это автоматическая проверка с мобильными параметрами, а не испытание на физическом iPhone.

Полный `integration.mjs` повторяет создание сводок и арки через настоящий frontend ST, серверное сохранение, штатный Hide, обычный запрос персонажа, группы, восстановление и импорт. Ответ модели в нём имитируется на границе HTTP. Существующие `settings-ui.mjs` и `settings-interactions.mjs` проверяют раскрытие, все шесть переходов, касания по иконке/тексту/краю, X и возврат управления.

Независимое ревью выявило проблему идентичности удалённой границы; исправление подтверждено отдельным тестом RED→GREEN. Дополнительно устранено устаревшее предупреждение после возврата лимита в допустимые пределы.

Итог перед публикацией: **56/56 unit-тестов**, проверка шести JavaScript-модулей, новый UI-сценарий в Chromium и WebKit, полный интеграционный сценарий ST, 18 касаний по шести кнопкам в WebKit и проверка размеров 320/375/390/430/1280 прошли. Проверены также запуск без самопроизвольного модального окна, повторная загрузка архива и отдельность чатов. Защищённые модули памяти совпадают с версией 1.0.0.
