# Согласованный интерфейс 1.3.0

9 ноября 2026 года. Обновление поверх 1.2.1 по «текст (3).txt». После просмотра интерактивного макета пользователь подтвердил внедрение. Это работающий UI существующего расширения с прежними данными и движком.

## Реализация

- Основной вход через меню у поля ввода впервые открывает «Активную память». Явные шесть кнопок в настройках продолжают открывать свои вкладки; повторное открытие сохраняет текущую вкладку.
- Шапка, навигация с иконками, сапфировые карточки с книжными метками, номером, отдельным названием и метаданными соответствуют одобренному направлению. Фактически активные статусы выделены мягким зелёным, архивные — серо-синим, замещение аркой — бронзовым. Все стили изолированы.
- Статус «Память для следующего ответа» показывает фактический объём и подключение. При выключении или блокировке фактический объём и индикатор равны нулю; объём выбранных записей подписан отдельно.
- Четыре быстрых действия: точный просмотр, копирование, обновление и глобальное выключение/включение. Просмотр и копирование используют тот же допустимый снимок, что реальная вставка движка.
- «Сейчас в памяти модели» и «Только в архиве» имеют пояснения и счётчики. Все записи берутся из общего архива и существующего memoryViewState; новый набор памяти UI не вычисляет.
- Сохранены лимит токенов, полный текст, отдельно подписанный предварительный текст при блокировке, все технические операции, версии, источники, архивный импорт/экспорт и восстановление. Полные тексты доступны отдельно, не раскрываются внутри карточек автоматически.
- Кнопка отдельного добавления замещённой сводки недоступна до отключения активной арки; рядом видно пояснение. Это UI-защита от вводящего в заблуждение действия. Правило подавления исходных сводок движком не изменено.

## Глобальное выключение

Раньше кнопка вызывала Engine.disableAll(), деактивируя каждую запись архива. По новому ТЗ она должна выключать общее внедрение, сохраняя подборку. Новый UI-обработчик меняет существующий settings.inject и сохраняет общие настройки. При явном включении также восстанавливается settings.enabled, если расширение было выключено полностью.

Архив и флаги записей не меняются. Прежний disableAll() не переписан: он по-прежнему используется для восстановления всех исходников. Способ формирования и внедрения памяти остался прежним.

## Общие вкладки без чата

Убрана общая блокировка всех вкладок при отсутствии сессии. Редакторы промптов, пресеты, общие настройки и резервная копия промптов доступны без открытого чата. Архивные экспорт/импорт/восстановление показываются с сохранённым чатом; без него есть пояснение. Фиктивные архивы не создаются.

## Регистрация пункта меню

Новый тест первого входа воспроизвёл отсутствие пункта: ST создаёт штатное wand-меню после загрузки сторонних расширений. Идемпотентное добавление выполняется сразу и на существующем APP_READY. Событие ST воспроизводится для поздних подписчиков; уникальный ID исключает дубли. Наблюдатель за всем DOM и повторные обработчики при открытии окна не добавлялись.

## Сохранность

src/core.js, src/engine.js, src/host.js, src/order.js, src/view-state.js и index.js не изменены относительно **v1.2.1**. Не менялись генерация, буквальные пользовательские промпты, отбор/порядок записей, защита дублей, хранение, журналы, Hide и восстановление. Формат данных прежний, миграций и очистки нет. Сохранены JSON-экспорт и тег v1.2.1.

Прежний лимит блокирует весь блок, а не выбирает за пользователя, какие записи отбросить. UI не помечает такие записи как фактически активные. Личная установка пользователя при разработке не открывалась и не изменялась.

## Проверки

Отдельная ST **1.19.0**, Node.js **24.16.0**, синтетические чаты, Chromium/Edge и Windows WebKit с параметрами iPhone 13.

- **69/69 unit-тестов**, проверка семи JS-модулей, согласованности версии UI/package/manifest и чистого diff. Новые проверки глобального переключения сначала падали, затем прошли.
- memory-workspace.mjs: общие промпты/создание пресета/сохранение и настройки без чата, отсутствие фиктивного архива, первый вход через меню, версия, иконки, два списка, точное совпадение просмотра/копирования с реальной вставкой, выключение/включение с полной неизменностью JSON архива, активация/деактивация, лимит, нулевой индикатор, отсутствие дублей и фоновых запросов, X и экраны 320×640 / 390×420 / 430×900 / 1280×900.
- В WebKit дополнительно проверено сохранение глобального выключения после перезагрузки, полная идентичность сохранённого архива, сохранность промптов и возврат точной прежней вставки после включения.
- manager-ui.mjs, Chromium: компактные границы, поиск/фильтры, множественный выбор, исходный и ручной порядок арки в настоящем HTTP-запросе, отсутствие дублей, сохранение после перезагрузки.
- ui-memory.mjs, Chromium: диапазон без автопоказа, отдельные статусы и выбор для арки, изменение реальной вставки, выключение/лимит/возврат, данные и границы после перезагрузки.
- integration.mjs, Chromium: сводка → редактирование → подтверждение → серверная проверка → Hide; арка и обычный ответ без дублей; независимые вставки WI/Summarize; лимит; промпты и данные после перезагрузки; чаты/ветки/группа; ошибка модели; незавершённая операция, журнал, восстановление и JSON merge.
- settings-interactions.mjs, WebKit: сохранение сворачивания, 18 касаний по иконке/тексту/краю шести кнопок, правильные вкладки, отсутствие повторного открытия, X и доступность ST после закрытия.
- compact-ui.mjs, WebKit с принудительно прежним HTML-шаблоном: совместимость кеша шапки, компактная главная, ленивый полный предпросмотр, несколько пересечений с архивом, блокировка повторного диапазона, карточки, поиск/выбор и неизменность данных.

Реальные снимки работающего расширения просмотрены. Независимое ревью полного изменения и дополнительной регистрации меню не выявило замечаний. В браузерных проверках нет необработанных ошибок страницы.

Ответ модели в интеграционных тестах имитируется на границе HTTP; ST, DOM, построение запроса, токенизаторы, сохранение и Hide настоящие. В WebKit-фикстуре отключён только встроенный TTS из-за отсутствия Web Speech API в Windows-сборке. Это проверка движка с мобильными параметрами, не физического iPhone и его клавиатуры. Причина ранее описанного зависания личной установки недоступна для подтверждения; тестовая установка загружается и открывает/закрывает UI без ошибок.
